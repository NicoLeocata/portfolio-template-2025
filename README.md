# Portfolio Template 2025

👉 Live demo: https://nicoleocata.github.io/portfolio-template-2025/

## Description

A production-ready, responsive portfolio template designed to be easy to customize and deploy.

## Features

- Mobile-first responsive layout
- Custom Bootstrap 5 theme (not default)
- Fluid typography using `clamp()`
- GSAP + ScrollTrigger animations
- Scroll-driven/parallax effects
- Accessibility-friendly (keyboard focus + `prefers-reduced-motion`)
- Custom 404 page

## Tech stack

- HTML5
- CSS3
- Bootstrap 5 (CDN)
- JavaScript (Vanilla)
- GSAP + ScrollTrigger

## Getting started

Clone the repository and run it with a local server (Live Server recommended).

```bash
git clone https://github.com/NicoLeocata/portfolio-template-2025.git
```

Then open index.html using a local development server.

## Customization

- Edit content directly in index.html

- Update styles in assets/css/

  - base.css: design tokens and fluid typography

  - ayout.css: layout and spacing

  - components.css: Bootstrap overrides and components

- Modify animations in assets/js/main.js

## Accessibility

- Semantic HTML structure

- Visible focus states

- prefers-reduced-motion support
